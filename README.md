# ✈️ Travelflow — Bespoke Travel Intelligence & Itinerary Platform

Travelflow is a dynamic, budget-aware travel itinerary planning web application built with Vite + React 19, styled with Plus Jakarta Sans & Inter typography, and featuring a modern black dot matrix background pattern.

## 🌟 Primary Features

1. **AI Trip Planner 3.0 (Centerpiece)**:
   - **Smart AI Configurator**: Source city, Destination (Goa, Manali, Jaipur, Kerala), Travel dates, Travelers count.
   - **Dynamic Budget Range Slider**: Live slider with quick-preset pills (`₹18k`, `₹28k`, `₹50k`, `₹90k`).
   - **Itinerary Pace Selector**: *Balanced*, *Relaxed*, and *High Energy*.
   - **Vibe & Focus Chips**: *Culture & Heritage*, *Culinary & Cafes*, *Scenic Nature*, *Adventure & Trails*.
   - **Natural Language AI Prompt Synthesis**: Build custom plans from freeform English prompts.

2. **Multi-Website Booking Price Comparison**:
   - Compare prices across **Booking.com**, **Agoda**, **MakeMyTrip**, **EaseMyTrip**, **IRCTC Rail Connect**, **ConfirmTkt**, **ixigo**, **Yatra**, **Hostelworld**, **IndiGo**, and **Air India**.
   - Zero agency markups; direct deep-link redirects with route pre-population.

3. **Live LLM AI Assistant**:
   - Embedded WhatsApp Concierge powered by the **Groq LLM API** (`openai/gpt-oss-120b`).
   - Simulated UPI/Card payment drawer with instant booking approval and demo PDF voucher generation.

4. **Hour-by-Hour Itineraries**:
   - Timed schedules with category filters (Attractions, Food, Transit, Buffer windows) and print capability.
